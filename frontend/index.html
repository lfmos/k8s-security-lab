01 / PROJECT

Do código ao cluster.

O projeto demonstra como uma aplicação pode ser empacotada, configurada e executada de forma reproduzível.

01 DESAFIO

Implantar frontend e backend como componentes independentes, disponíveis e preparados para escalar.

O Kubernetes mantém o estado desejado da aplicação, reinicia contêineres com falha e distribui o tráfego entre as réplicas disponíveis.

04 / KUBERNETES

Infraestrutura declarada em YAML.

Os manifestos descrevem a quantidade de réplicas, as verificações de saúde, os recursos disponíveis e a forma como os serviços se comunicam.

  • 01 Deployments de frontend e backend
  • 02 Services para comunicação interna
  • 03 Readiness e liveness probes
  • 04 Autoscaling baseado em CPU
backend-deployment.yml 
apiVersion: apps/v1
kind: Deployment

metadata:
  name: backend

spec:
  replicas: 2

  template:
    spec:
      containers:
        - name: backend
          image: lfmos/cluster-sentinel-backend

          readinessProbe:
            httpGet:
              path: /ready
              port: 8080

          resources:
            requests:
              cpu: 100m
              memory: 64Mi
